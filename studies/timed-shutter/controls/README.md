# Timed-shutter transfer controls

This is a separate physical-timing task, not a new gate variant or builder
treatment. Its barrier is thin along X rather than Z. The `rotated-working`
control turns the same barrier 90 degrees in the generated candidate project.
The fixed Studio runner, trajectory classifier and plugin are identical to the
cooperative-gate passage follow-up.

The working source is evaluator-side material and is not present in the public
task seed. `state-only-open` deliberately reports an open state while retaining
collision. `passable-while-closed` deliberately removes collision during the
closed state. They test whether physical passage is measured independently of
the replicated state flag.

These authored sources and contrasts are regression authorities. The old standalone
launcher is retired. New captures must register the source against a current compiled
eval and run through the shared operator quote, journal, driver and native adapter.
Historical receipts remain read-only archives; their evaluator definitions are not
loaded through current readers. A retained still alone establishes no visual verdict.
