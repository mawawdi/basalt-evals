# Authored bomb worker control

`server-authoritative/` is an evaluator-side control for the bomb-passing
execution path. The builder receives only the public seed and task view; this
source is never copied into a builder workspace or included in a model prompt.
It is not a builder treatment, an expert label, or a visual-grade reference.

The server owns holder selection, distance checks, one fuse deadline, damage
and disconnect cleanup. The client sends an argument-free pass request on a real
`E` press and renders the replicated state. The solo path allows a bounded
grace period before arming so Studio can admit a second player in a multiplayer
round. That grace period is a control implementation choice, not a hidden
requirement for builders; the public two-player start rule needs clarification
before the next comparison is frozen.

The create-only run of 2026-09-21 verified all 16 required deterministic criteria
with signed evidence. The capture has no visual judgment.
